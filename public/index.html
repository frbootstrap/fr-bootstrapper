Ta clé TMDB

TMDB, c’est la grande base de données des films et séries. Certains addons s’en servent pour savoir exactement quel film tu cherches (titre français, année). Sans clé, ils ne peuvent pas marcher.

WaCustomTéléchargements directs 1fichier, débridés par AllDebrid ou TorBox.

Comment l’avoir ?
  1. Crée un compte gratuit sur themoviedb.org.
  2. Va sur Paramètres → API et demande une clé (usage personnel).
  3. Copie le « jeton d’accès en lecture de l’API », le plus long des deux (il commence par eyJ).

Gratuit · fortement conseillé

Tes trackers

Un tracker, c’est un site communautaire qui répertorie des torrents, souvent en VF. Avec un compte, tu donnes aux addons accès à son catalogue : beaucoup plus de résultats en français. Inscris-toi, puis copie ta clé API ici.

      Comment savoir si ça a marché ?

      La dernière ligne dit « Terminé : … addons installés ». Relance ton appli : les addons apparaissent sur tous tes appareils.

      Un addon affiche ✗ ?

      Pendant l’installation, un ✗ veut dire que cet addon ne répondait pas à ce moment-là : il est sauté, les autres sont installés quand même. Repasse plus tard pour l’ajouter.

      Mes clés sont-elles gardées ?

      Non. Tes clés servent à fabriquer tes liens d’addons puis sont oubliées : rien n’est enregistré. Seul un compteur d’installations existe : un simple nombre, sans rien sur toi. Le code est public.
